### وردەکاری

**٩٠ — بیرخستنەوەی خۆکار لابرا.** `sarraf_send_due_debt_reminders` سڕایەوە. خوێنەرەکە مایەوە (پرسیار وەڵام دەداتەوە، هیچ نانێرێت). ئەو بیرخستنەوانەی پێشتر نێردراون **نەسڕدراونەتەوە**. ٤ چێک، هەر سێ پارێزەرەکە بە ئینجێکشن سەلمێنران.

**٨٧ — قاسەی کڕیار.** دوو نیوەکە: پارەکەیان لە قاسەی گشتی دیارە بەڵام خاوەن ناتوانێت خەرجی بکات؛ کاتێک شتێک دەکڕن خۆکارانە لە پارەی خۆیان دەبردرێت. **دوو کێشەی ڕاستەقینە دۆزرانەوە:** پارەکە دوو جار دەبردرا (تریگەرێک و `update`ـێک پێکەوە)، و §11ـی «ماوەکە ببێتە قەرز» هەر نەکرابوو. ٩ چێک، ٧ ئینجێکشن.

**٨٩ — عمولە.** سێ خانەی نوێ: هەقی کار، بۆ کوێ چوو، بۆ کێ کرا. هەقی کار **بە ئەنقەست لەسەر ڕیزی مامەڵەکە دانەنراوە** بۆ ئەوەی کڕیار نەیبینێت. کۆمێنتە هەڵەکەی `202609020005` («There is no fee on the side») پەشیمان کرایەوە. **پارێزەری NaNـی خۆم هەڵە بوو** — `numeric` لە PostgreSQLـدا IEEE ناکات. ٩ چێک + ٤ تێست.

**٨٨ — چەند فرۆشیار.** ڕەتکردنەوەی «تەنها دوو ڕیز» لە **پێنج شوێن** نووسرابوو. مۆدیوولێکی نوێ (`directTrade.js`) ژمێریارییەکەی لە `App.jsx` دەرهێنا. ٧ چێک + ٩ تێست، ٦ ئینجێکشن.
