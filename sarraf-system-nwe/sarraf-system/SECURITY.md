# چۆن ZEMAN بازرگانییەکان لە یەکتر جیا دەکاتەوە

ئەم پەڕەیە بۆ ئەو کەسەیە کە دوای ئێمە ئەم سیستەمە بەڕێوە دەبات. هەموو یاسایەکی
لێرەدا بە دەروازەیەکی خۆکارەوە بەندە کە ڕەت دەکاتەوە گەر بشکێت — بۆیە هەر
ڕستەیەک لێرەدا شتێکە کە دەکرێت بسەلمێندرێت، نەک شتێک کە نیازمان لێی بووە.

---

## سێ پلە

| پلە | کێیە | `role` | `admin_level` | `tenant_id` |
|---|---|---|---|---|
| **ماناجەر** | خاوەنی پلاتفۆرم، ئەوەی دەیفرۆشێت | `admin` | `manager` | **null** |
| **سەرخێڵ / وەتەن** | ئەو بازرگانییەی سیستەمەکەی کڕیوە | `admin` | `owner` | بازرگانییەکەی |
| **ئەدمین** | ستافی خاوەنەکە | `admin` | `operator` | بازرگانییەکەی |
| نووسینگە، هاوبەش، وەبەرهێنەر، کڕیار | ئەندامانی بازرگانییەک | ڕۆڵی خۆیان | — | بازرگانییەکەی |

ماناجەر تاکە پلەیە کە `tenant_id`ـی nullـە. ئەمە بە تریگەری
`sarraf_guard_tenant_membership` جێبەجێ دەکرێت: هەموو ئەکاونتێکی تر دەبێت
بازرگانییەکی هەبێت، و ماناجەر نابێت هیچی هەبێت.

---

## سێ چینی جیاکردنەوە

### ١. پۆلیسییەکانی ڕیز (RLS)

هەموو خشتەیەک کە `tenant_id`ـی هەیە:

- `enable row level security` — پۆلیسییەکان جێبەجێ دەکرێن؛
- `force row level security` — **خاوەنی خشتەکەش** لێی بەدەرناکەوێت؛
- پۆلیسییەکی `RESTRICTIVE` کە بە `AND` لەگەڵ هەموو پۆلیسییەکی تر دەبەسترێت.

`RESTRICTIVE` گرنگە. پۆلیسی ئاسایی بە `OR` دەبەسترێت، بۆیە زیادکردنی
پۆلیسییەکی نوێ دەستڕاگەیشتن **فراوان** دەکات. پۆلیسی سنووردارکەر بە `AND`
دەبەسترێت، بۆیە جیاکردنەوەی بازرگانی شتێکە کە هیچ پۆلیسییەکی داهاتوو
ناتوانێت بیشکێنێت.

یاساکە یەکجار نووسراوە، لە `sarraf_tenant_visible(text)`:

```sql
select public.sarraf_sees_all_tenants()
    or (p_tenant is not null and p_tenant = public.sarraf_tenant());
```

`p_tenant is not null` بەشێکی گرنگە: دوو نەزانراو یەک بازرگانی نین.

**لە پۆلیسییەکاندا** بە شێوەی ساب-کوێری دەنووسرێت نەک بانگکردنی فەرمانەکە:

```sql
using ((select public.sarraf_sees_all_tenants())
       or (tenant_id is not null and tenant_id = (select public.sarraf_tenant())))
```

هەمان وەڵامە، بەڵام جارێک بۆ هەر دەقێک هەڵدەسەنگێندرێت نەک جارێک بۆ هەر
ڕیزێک. `verify:scale` ئەوەی تر ڕەت دەکاتەوە.

### ٢. `sarraf_definer` — ڕۆڵێک کە بەسەر هیچ شتێکدا تێناپەڕێت

١٦٣ فەرمانی `SECURITY DEFINER` هەیە. فەرمانێکی وا بە مافی **خاوەنەکەی**
کار دەکات، نەک بانگهێشتکەرەکەی. گەر خاوەنەکەی `postgres` بێت، ئەوا
`BYPASSRLS`ـی هەیە و هەموو پۆلیسییەک نادیدە دەگرێت — واتە هەر فەرمانێک
ڕێگایەکی ڕاستەوخۆیە بەناو جیاکردنەوەکەدا.

بۆیە `sarraf_definer` هەیە: ڕۆڵێکی `NOBYPASSRLS` کە ئەندامی
`authenticated`ـە. فەرمانێک کە ئەو خاوەنیەتی تەنها ئەو ڕیزانە دەبینێت کە
بازرگانیی بانگهێشتکەرەکە دەیبینێت.

**دوو دەربازبوون هەیە، و هەردووکیان مەرجێکی هەیە:**

| فەرمان | بۆچی | مەرجەکە |
|---|---|---|
| `sarraf_receipt_record_server_extraction` | سێرڤەر بە کلیلی خۆی بانگی دەکات، بێ `auth.uid()` | هیچ وێبگەڕێک ناتوانێت بانگی بکات |
| `sarraf_office_payment_attach_evidence_server` | هەمان | هەمان |
| `sarraf_manager_support_tenant_for` | هەمان | هەمان |

`verify:isolation` هەردوو لایەن دەپشکنێت: هیچ فەرمانێکی تر ناتوانێت
تێبپەڕێت، و ئەم سێیە بۆ هیچ وێبگەڕێک کراوە نین.

**زیادکردنی فەرمانێکی نوێ:** دوای `create function` پێویستە:

```sql
grant create on schema public to sarraf_definer;
alter function public.sarraf_new_thing(...) owner to sarraf_definer;
revoke create on schema public from sarraf_definer;
```

ئەو `grant`/`revoke`ـە **پێویستە**. سپاردنی فەرمانێک بە ڕۆڵێک وەک ئەوە
هەڵدەسەنگێندرێت کە ئەو ڕۆڵە درووستی بکات لە سکیمادا. fixtureـە خۆماڵییەکە
وەک superuserێک پەیوەندی دەکات کە خاوەنی سکیماکەیە، بۆیە **ناتوانێت** ئەم
هەڵەیە بگرێت — یەکجار بەم شێوەیە لەسەر داتابەیسی زیندوو شکا.
`verify:source` ئێستا دەیگرێت.

### ٣. ڕێڕەوەکانی API کە کلیلی خزمەتگوزاری هەڵدەگرن

چوار ڕێڕەو کلیلی خزمەتگوزاری هەڵدەگرن، واتە RLS بۆ هەموو ئەوەی دەیخوێننەوە و
دەینووسن کوژێنراوەتەوە:

- `api/admin-user.js`
- `api/receipt-ingestion.js`
- `api/receipt-ocr.js`
- `api/office-payment-evidence.js`

**هەموو سنوورێکی بازرگانی کە داتابەیس دەیپاراست، دەبێت لەوێدا بە JavaScript
بپارێزرێت.** یاساکە لە `api/_tenant.js` نووسراوە:

1. ئەکتەرێکی بێ بازرگانی ناتوانێت دەستی لە ڕیزێکی بازرگانیدار بدات؛
2. ئەکتەرێکی بازرگانیدار تەنها ڕیزەکانی بازرگانیی خۆی؛
3. **ڕەتکردنەوەکە نابێت بڵێت کامیان بوو** — «ئەمە هی کەسێکی ترە» و «ئەمە
   بوونی نییە» دەبێت وەک یەک بخوێندرێنەوە، نەک ڕەتکردنەوەکە خۆی ببێتە
   ڕێگایەک بۆ دۆزینەوەی تۆمارەکانی بازرگانییەکی تر.

`verify:source` داوا دەکات هەر ڕێڕەوێکی کلیلی خزمەتگوزاری بازرگانیی
ئەکتەرەکە **بار بکات** و **بەراوردی بکات**. سەلمێنراوە کە شێوە کۆنەکەی
`receipt-ocr.js` ڕەت دەکاتەوە.

## ماناجەر: پشتگیرییەک، نەک دەستڕاگەیشتنی بێ سنوور

ماناجەر هی هیچ بازرگانییەک نییە و `sarraf_sees_all_tenants()` بۆی ڕاستە،
بۆیە هەموو پۆلیسییەک ڕێگای دەدات. ئەمە بۆ **خوێندنەوە** ڕاستە: بەڕێوەبەری
پلاتفۆرمە و دەبێت بزانێت ئایا دامەزراوەکە تەندروستە.

بۆ **کردار** نا. کردارێک لەسەر بازرگانییەک پێویستی بە پشتگیرییەکی کراوە هەیە:

```sql
select public.sarraf_manager_open_support('t-sarkhel', 'هۆکارەکە', 120);
```

- هۆکارێک لانیکەم ٨ پیت پێویستە؛
- ماوەکە لە نێوان ١٥ خولەک و ٨ کاتژمێردایە، و ئەمە لە **سکیمادا** بەندە
  (`check (expires_at <= opened_at + interval '8 hours')`) نەک تەنها لە
  فەرمانەکەدا — بۆیە نووسینی ڕاستەوخۆی ڕیزەکە ناتوانێت تێیپەڕێنێت؛
- کردنەوەی دووەم یەکەم دادەخات — دوو بازرگانی بە یەک کات پشتگیری نییە؛
- **خاوەنی ئەو بازرگانییە ڕیزەکە دەبینێت**، و ناتوانرێت بسڕدرێتەوە.

ئەمە ئەو پرسیارەیە کە کڕیارێک دەیکات پێش ئەوەی دەفتەرەکەی بە سۆفتوێری
کەسێکی تر بسپێرێت: «ئایا فرۆشیارەکە چووەتە ناو حسابەکانمەوە؟» ئێستا
وەڵامێکی هەیە.

## هیچ پارەیەک بێ بازرگانی

`tenant_id` بە `default public.sarraf_tenant()` دێت، کە `auth.uid()`
دەخوێنێتەوە. ئەمە بۆ کەسێکی چووەژوورەوە ڕاستە و بۆ هەموو شتێکی تر هەڵە:
کلیلی خزمەتگوزاری، تریگەرێک لەناو فەرمانێکی definerدا، و پەیوەندییەکی
چاکسازی هیچیان `auth.uid()`یان نییە.

ڕیزێک کە بە `tenant_id = null` دادەنیشێت **بۆ هەمووان نادیارە** — لەبەر ئەوەی
پۆلیسییەکان سنووردارکەرن. پارەیەک کە کەس نایبینێت لە پارەیەکی لە شوێنی
هەڵەدا خراپترە.

بۆیە دوو تریگەر:

| تریگەر | لەسەر | ڕەفتار |
|---|---|---|
| `sarraf_require_tenant` | `txs`, `ledger`, `journal_entries`, `receipts`, `receipt_batches`, `zeman_notifications` | بازرگانییەکە لە ڕیزەکەوە دەردەهێنێت؛ گەر نەیدۆزێتەوە **ڕەت دەکاتەوە** |
| `sarraf_note_tenant` | `notes`, `audit`, `system_event_log`, `receipt_state_transitions`, `receipt_extractions`, `receipt_ocr_attempts` | هەمان، بەڵام گەر نەیدۆزێتەوە **ڕێگا دەدات** |

جیاوازییەکە بە ئەنقەستە. تریگەرێک کە دەتوانێت پارەدانێک ڕەت بکاتەوە چوونکە
نەیتوانی ئۆدیتەکە ناو ببات، کێشەیەکی تۆمارکردن دەکاتە وەستانی خزمەتگوزاری.

## دوو شت کە دەبێت بزانرێن

**١. پشکنینی داتابەیسە زیندووەکە.** `Actions → Inspect the database`.
خوێندنەوەی ڕەق، تراکنزاکشنێکی `read only`. هەموو ژمارەیەک لە
`supabase/INSPECT.sql`ـەوە دێت و لە `BASELINE.md`ـدا تۆمار کراوە.

**٢. جێبەجێکردنی مایگرەیشن.** `Actions → Apply database migrations`،
`confirm: APPLY`. **هەمیشە یەکەم جار بە `dry_run: true`** — لیستی ئەو
فایلانەت پیشان دەدات کە دەڕۆن، بێ ئەوەی هیچ بگۆڕێت.
